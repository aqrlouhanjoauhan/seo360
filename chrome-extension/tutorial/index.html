SEO360 SETUP GUIDE

Direct Access to Raw SEO Infrastructure

DataForSEO is the underlying data infrastructure powering top-tier SEO software, rank trackers, and analytics tools globally. By connecting directly, you skip third-party markups and access enterprise data at wholesale rates.

1

Create Your Account

Register directly on the official DataForSEO platform

Sign up to get started. New accounts receive complimentary test credits to explore the APIs.

2

Get Your API Credentials

Locate your Login Email and API Password token

Once logged in, open the left sidebar and go to Dashboard → API Access:

  • API Login: Your account email
  • API Password: The generated API key token (click copy)
Click to view full image
3

Launch & Debug

Connect your keys and start querying SEO endpoints

Open the SEO360 Console, paste both credentials into the left sidebar, and click Save Credentials.
